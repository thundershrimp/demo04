# clitodo · 命令行待办事项工具

一个用 Python 写的、**零第三方依赖**的命令行待办清单（CLI Todo）。一条命令记一件事，随时查、随时勾。

```console
$ python todo.py add "买牛奶" -p high -d tomorrow
✓ 已添加 #1：买牛奶，到期 2026-10-26

$ python todo.py ls
ID  状态    优先级     内容              到期
────────────────────────────────────────
 1  [ ]  高       买牛奶             2026-10-26 明天
 2  [ ]  中       交房租             2026-10-20 逾期5天
 3  [ ]  低       看《CLI 设计》       

  共 3 条显示 / 未完成 3 条
```

## 一、先说清楚：命令行到底是个啥？

### 1. 一句话版本

**命令行（Command Line）就是一个"你说一句、它做一件"的输入框。**

平时你用微信，是点图标、点按钮；用命令行，是把"想让它干的事"用文字写出来，回车执行。
那个黑色的窗口叫**终端（Terminal）**，负责显示和接收文字；里面跑着的程序叫 **Shell**（Windows 上是 PowerShell / CMD，macOS 和 Linux 上是 bash / zsh），负责理解你打的字并去执行。

### 2. 它和你熟悉的图形界面（GUI）是同一件事

点鼠标和打字，本质上都是给电脑下指令，只是"下单方式"不同：

| | 图形界面（点鼠标） | 命令行（打字） |
|---|---|---|
| 怎么操作 | 找图标 → 点开 → 点下一步 | 打一行命令 → 回车 |
| 学起来 | 直观，看一眼就会 | 要记几个词，半天就够用 |
| 干重复的事 | 一百次就要点一百次 | 写一行，跑一万次 |
| 能不能自动 | 很难 | 天然可以写进脚本定时跑 |
| 精细控制 | 只有界面给你的按钮 | 几乎每个参数都能调 |
| 远程操作 | 基本不行 | 一根 SSH 就能操作千里之外的服务器 |

所以它没被淘汰，反而一直是程序员、运维、数据工程师的主力工具——**不是因为它高级，而是因为它快和可复制**。

### 3. 一条命令长什么样

```
python  todo.py  add  "买牛奶"  -p  high  -d  tomorrow
  ↑        ↑      ↑      ↑       ↑    ↑     ↑    ↑
 程序   脚本文件  子命令  参数值   选项  选项值 选项 选项值
```

拆开看永远是这几个零件：

- **程序名**：`python`、`git`、`node` —— 你要启动哪个程序。
- **参数（argument）**：传给程序的数据，比如 `"买牛奶"`。
- **选项（option / flag）**：以 `-` 或 `--` 开头，用来调整行为，比如 `-p high` 指定优先级。
- **退出码（exit code）**：程序干完活会返回一个数字，`0` 表示成功，非 `0` 表示出了某种错。写脚本自动化全靠它判断"上一步到底成没成"。

程序把结果打在**标准输出（stdout）**，把错误打在**标准错误（stderr）**。这两个流可以分别重定向到文件，也是命令行能"拼装"的基础。

### 4. 三个立刻能用的组合技巧

| 符号 | 作用 | 例子 |
|---|---|---|
| `>` / `>>` | 把输出写进文件 / 追加到文件末尾 | `python todo.py ls --json > todo.json` |
| `\|` | 把前一个命令的输出喂给后一个 | `python todo.py ls \| grep 牛奶` |
| `&&` | 前一个成功了再执行后一个 | `python todo.py done 1 && python todo.py stats` |

**这就是命令行的真正威力：每个小程序只管一件事，靠管道串起来就能拼出复杂流程。** 图形界面是"一个大软件什么都有"，命令行是"很多小工具自由组合"。

### 5. 命令行能干什么（举点实际的）

- **管文件**：批量重命名 300 张照片、按日期归档、找出所有大于 100MB 的文件。
- **管代码**：`git` 提交代码、`npm` 装依赖、`pytest` 跑测试——几乎所有开发工具的第一入口都是命令行。
- **管服务器**：SSH 登录远程机器、看日志、重启服务，服务器上通常根本没有图形界面。
- **跑数据**：`python analyze.py` 每天定时处理几十万行数据，人可以不用守着。
- **自动化**：把十步操作写进一个脚本，以后一次运行全部搞定（比如"备份数据库 → 压缩 → 上传 → 发通知"）。
- **调 AI / 调 API**：`curl` 发一个 HTTP 请求，几秒钟就能验证一个接口通不通。

一句话总结：**图形界面适合"偶尔做一次、需要看效果"的事；命令行适合"重复做很多次、要求精确、要能自动化"的事。**

## 二、快速开始

要求：Python 3.9 以上（无任何第三方依赖）。

```bash
git clone https://github.com/thundershrimp/demo04.git
cd demo04

# 直接运行
python todo.py add "写周报" -p high -d 2026-10-31
python todo.py ls
```

想少打几个字，可以起个别名（写进 `~/.bashrc` 或 PowerShell 的 `$PROFILE`）：

```bash
alias todo='python /绝对路径/demo04/todo.py'
```

之后就能这样用：`todo add "买牛奶"`。

## 三、命令一览

| 命令 | 别名 | 说明 |
|---|---|---|
| `add <内容>` | `a` | 添加待办，支持 `-p` 优先级、`-d` 到期日 |
| `list` | `ls` / `l` | 列出待办，支持 `--all`、`--priority`、`--tag`、`--json` |
| `done <编号...>` | `d` | 标记完成，可写多个或区间：`1 3-5` |
| `undone <编号...>` | `u` | 取消完成 |
| `rm <编号...>` | | 删除 |
| `edit <编号> [新内容]` | `e` | 修改内容 / 优先级 / 到期日 |
| `search <关键字>` | `s` | 搜索内容 |
| `clear` | | 清理所有已完成的（`-y` 跳过确认） |
| `stats` | | 完成率、逾期数、各优先级分布 |
| `doctor` | | 检查数据文件位置与运行环境 |

优先级可以写 `high/normal/low`，也可以直接写 `高/中/低`。
到期日支持 `2026-11-01`、`11-01`（默认今年）、`today` / `今天`、`tomorrow` / `明天`。

### 常用示例

```bash
# 加三条，优先级和截止时间都不同
python todo.py add "买牛奶" -p high -d tomorrow
python todo.py add "交房租" -d 2026-11-01
python todo.py add "看《CLI 设计》" -p 低

# 只看高优先级
python todo.py ls -p high

# 完成第 1 条和第 3 到 5 条
python todo.py done 1 3-5

# 改内容 + 改日期
python todo.py edit 2 "交水电费" -d 2026-11-05

# 搜一下
python todo.py search 房租

# 统计进度
python todo.py stats

# 输出 JSON，交给别的程序处理
python todo.py ls --all --json | python -m json.tool
```

## 四、数据存在哪

默认在 `~/.clitodo/todos.json`（Windows 是 `C:\Users\<你>\.clitodo\todos.json`）。
想换位置，设一个环境变量就行：

```bash
export CLITODO_DB="/d/我的数据/todo.json"     # macOS / Linux / Git Bash
$env:CLITODO_DB = "D:\我的数据\todo.json"      # PowerShell
```

写文件时采用**先写临时文件、再原子替换**的方式，中途断掉也不会把原数据写坏。

数据结构：

```json
{
  "next_id": 2,
  "items": [
    {
      "id": 1,
      "title": "买牛奶",
      "done": false,
      "priority": "high",
      "due": "2026-10-26",
      "created": "2026-10-25T17:29:37",
      "done_at": null
    }
  ]
}
```

## 五、退出码

| 退出码 | 含义 |
|---|---|
| `0` | 成功 |
| `1` | 业务错误（比如编号不存在、数据文件损坏） |
| `2` | 参数写错了（日期非法、未知优先级） |
| `130` | 用户按了 Ctrl+C |

## 八、可以自己动手加的功能

留给你练手的几个方向，都不难：

1. **标签系统**：`add "买牛奶" #生活`，然后 `ls -t 生活` 过滤（现在 `-t` 是简单的子串匹配）。
2. **重复任务**：支持 `--every day/week`，完成后自动生成下一条。
3. **优先级排序权重可配**：现在固定按 高→中→低，可以改成"逾期最紧急优先"。
4. **导出 Markdown**：`todo export > 今日待办.md`。
5. **多清单**：用 `--list work` 区分工作和生活。
